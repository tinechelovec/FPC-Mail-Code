## 📦 Установка и обновление

1. Скачайте плагин из репозитория GitHub: **[FPC-Mail-Code](https://github.com/tinechelovec/FPC-Mail-Code)**.
2. Откройте Telegram-бота **FunPay Cardinal**.
3. Перейдите в меню **Плагины**.
4. Нажмите **➕ Добавить плагин**.
5. Отправьте боту скачанный файл плагина **Mail-Code**.
6. После установки обязательно выполните команду:

```text
/restart
```

После перезапуска плагин появится в списке установленных плагинов.

## ⚙️ Главное меню настроек

При первом запуске откройте настройки **Mail-Code**.

![Главное меню настроек Mail Code](https://img2.teletype.in/files/9c/07/9c077471-176a-4517-9232-c2da7e423944.png)

В меню доступны следующие разделы:

- **🧩 Состояние плагина** — включение и выключение Mail Code.
- **📬 Почтовые ящики** — добавление и настройка почтовых аккаунтов.
- **🔔 Уведомления** — настройка уведомлений плагина.
- **⏱ Окно поиска писем** — время, за которое плагин ищет подходящие письма.
- **⌛ Кулдаун спама** — задержка между повторными вызовами команды одним покупателем.
- **💬 Шаблоны сообщений** — настройка сообщений, которые плагин отправляет пользователям.
- **⛔ Чёрный список** — добавление и управление заблокированными покупателями.
- **🧰 Обслуживание** — работа с логами и конфигурацией плагина.

## 📬 Добавление почты

Откройте раздел **Почтовые ящики** и нажмите **➕ Добавить почту**.

![Кнопка добавить почту](https://img1.teletype.in/files/07/dd/07dddf57-77f5-4e91-8ccb-1f047945809f.png)

Выберите почтового провайдера.

![Выбор почтового провайдера](https://img1.teletype.in/files/ca/56/ca566583-6cbb-4de3-bc0c-c6381497b8cd.png)

Способ подключения зависит от провайдера:

- **Outlook / Hotmail** — рекомендуется автоматическая привязка через браузер.
- **Gmail / Yandex / Mail.ru** — используется IMAP и пароль приложения.
- **Firstmail / Notletters / SmakMail** — подключение выполняется по данным почты.

## 🔵 Outlook / Hotmail

Выберите **Outlook / Hotmail**.

![Подключение Outlook Hotmail](https://img2.teletype.in/files/19/cf/19cf2afd-9039-4aa7-8c05-a52df646e6c9.png)

Плагин предложит два варианта:

1. **🌐 Войти в браузере** — автоматическая привязка. Это рекомендуемый способ.
2. **✍️ Ввести токен / данные вручную** — ручной ввод данных аккаунта или Refresh Token.

При ручном варианте доступны несколько форматов ввода.

![Ручной ввод Outlook](https://img2.teletype.in/files/99/40/9940a0ea-3e2b-4004-9871-2f1514b2b9fc.png)

### Автоматическая привязка

Нажмите **🌐 Войти в браузере**. Откроется страница Microsoft.

Выберите нужную учётную запись или войдите в неё.

![Выбор учётной записи Microsoft](https://img4.teletype.in/files/b7/00/b7001a94-3801-4530-97ea-208039c97d37.png)

Если Microsoft запросит разрешение для приложения, подтвердите его.

После успешной авторизации появится сообщение о подключении почты.

![Почта Outlook успешно подключена](https://img1.teletype.in/files/4a/c8/4ac8acbb-3c1c-429a-a5d0-d684c823dbe8.png)

Вернитесь в Telegram-бота Cardinal. Плагин автоматически получит и сохранит необходимые данные.

![Outlook подключён в Cardinal](https://img3.teletype.in/files/a9/93/a993158b-5d95-448d-94a5-20efaa5b9746.png)

## 🔴 Gmail / Yandex / Mail.ru через пароль приложения

Для **Gmail**, **Yandex** и **Mail.ru** используется подключение через IMAP и **пароль приложения**.

Выберите нужный сервис. Ниже показан пример для Gmail.

![Выбор Gmail Yandex Mail.ru](https://img1.teletype.in/files/8d/2c/8d2cdfa6-33d2-4e05-827d-8b6033ca9d92.png)

### Пример настройки Gmail

Откройте Gmail и нажмите на аватар профиля в правом верхнем углу.

![Аватар Gmail](https://img1.teletype.in/files/4a/a8/4aa8dea0-f9a9-4e9c-927a-c9d797b0474e.png)

Нажмите **Manage your Google Account / Управление аккаунтом Google**.

![Управление аккаунтом Google](https://img2.teletype.in/files/17/da/17da6713-2913-467c-bf84-60a615a3b62d.png)

Перейдите в раздел **Security & sign-in / Безопасность** и убедитесь, что у аккаунта включена **двухэтапная аутентификация (2FA)**.

![Настройки безопасности Google](https://img1.teletype.in/files/c4/2a/c42a6a89-f8dd-4696-8bc7-254fb4c6c30a.png)

После включения 2FA найдите в настройках Google пункт **App passwords / Пароли приложений**.

![Поиск пароля приложения](https://img4.teletype.in/files/fd/af/fdafa282-0a7b-414d-b511-2bdca2f960d8.png)

Введите любое понятное название приложения, например:

```text
Mail Code
```

![Создание пароля приложения](https://img2.teletype.in/files/92/38/9238dcfd-70bf-4a8a-8ebc-5d5fc4916ca3.png)

Google выдаст отдельный пароль приложения. Скопируйте его.

![Сгенерированный пароль приложения](https://img3.teletype.in/files/a9/2f/a92ffae4-d862-4441-9d14-aef552b0bbdb.png)

> [!IMPORTANT]
> Не публикуйте пароль приложения и не передавайте его другим людям. На скриншотах приватные данные скрыты.

Вернитесь в Cardinal и отправьте данные в формате:

```text
почта@gmail.com:пароль_приложения
```

Например:

```text
example@gmail.com:abcdabcdabcdabcd
```

После добавления плагин проверит соединение с почтой.

![Успешная проверка подключения](https://img4.teletype.in/files/ba/e0/bae0dca7-8304-4077-8d62-65c042eaf551.png)

## 🎯 Выбор сервиса и команды

После подключения почты выберите сервис, с которого плагин должен получать проверочные коды.

Доступны, например:

- Steam
- Epic Games
- Discord
- Battle.net
- Riot Games
- Ubisoft
- Supercell
- Telegram
- Roblox
- **Универсальный** режим
- Собственный фильтр

![Выбор сервиса](https://img2.teletype.in/files/17/2d/172d47c9-1089-4d1e-8179-dc5ca8d64abd.png)

Если одна почта используется для разных сервисов, можно выбрать **🌐 Универсальный**.

После этого задайте команду, которую покупатель будет писать в чате FunPay, например:

```text
!code_all
```

После успешного добавления появится карточка с данными почты.

![Почта успешно добавлена](https://img1.teletype.in/files/4d/68/4d68d4c4-7ce4-48d3-92c8-c12981e10710.png)

## 💬 Как покупатель получает код

Покупатель выполняет вход в нужный сервис и запрашивает проверочный код на подключённую почту.

После этого он возвращается в чат FunPay и пишет команду, которую вы указали при настройке почты, например:

```text
!code_mail
```

Плагин находит подходящее письмо и отправляет найденный код в чат.

![Выдача кода покупателю](https://img3.teletype.in/files/a1/2a/a12a0785-c2a1-4502-a2f1-875a7a4caea2.png)
